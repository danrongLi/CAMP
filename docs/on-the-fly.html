On-the-fly CAMP

Run the CAMP1–4 scripts supplied for the human fetal atlas analysis.

Script location

Repository folder
MetaCell_Construction_Pipeline/CAMP/on_the_fly_for_human_fetal_atlas_data/
    CAMP1.py
    CAMP2.py
    CAMP3.py
    CAMP4.py

The on-the-fly CAMP2 and CAMP3 implementations compute similarities between cells and representatives in blocks, without storing a global dense cell-by-cell similarity matrix. The input data and PCA coordinates still remain in memory.

1. Set the input and output paths

The original workflow uses the human fetal atlas data from the dataset folder. Edit the paths in each script's if __name__ == '__main__': block:

  • CAMP1: update both the loompy.connect(...) path and input_file to the same loom file. Also update the processed .h5ad path in write_h5ad(...) and the membership output_file.
  • CAMP2 and CAMP3: set input_file to the processed .h5ad saved by CAMP1, and set each membership output_file.
  • CAMP4: set input_file to that same processed file and set out_csv. Its supplied main block currently points to a PBMC file; change it when running the atlas data.

Create the parent directories for the processed data and CSV outputs. Use a separate output CSV for each variant.

2. Set the granularity

Edit gamma_list in each script. The requested number of representatives is calculated from int(N / gamma). Choose gamma using the retained cell count and check the actual metacell count afterward. CAMP3 needs at least two requested representatives.

3. Run the scripts

Run CAMP1 first if you need it to prepare the atlas data. Then run the other variants on its saved processed file:

Terminal
python MetaCell_Construction_Pipeline/CAMP/on_the_fly_for_human_fetal_atlas_data/CAMP1.py
python MetaCell_Construction_Pipeline/CAMP/on_the_fly_for_human_fetal_atlas_data/CAMP2.py
python MetaCell_Construction_Pipeline/CAMP/on_the_fly_for_human_fetal_atlas_data/CAMP3.py
python MetaCell_Construction_Pipeline/CAMP/on_the_fly_for_human_fetal_atlas_data/CAMP4.py

If the matching processed file is already available, CAMP2–4 can be run directly after their paths are updated. The input for CAMP2 and CAMP3 must include obsm['X_pca'].

The atlas CAMP1 script computes PCA without the scaling used by the regular PBMC CAMP1–3 scripts. Use the intended preprocessing and input consistently when comparing methods.

Output

Each script saves a CSV with cell identifiers as row names, one membership column per gamma, and corresponding _is_seed columns marking the initially sampled cells. For example, 40 contains memberships for gamma=40, and 40_is_seed contains seed flags. The number of unique membership labels gives the actual number of metacells.

Use a new output path for each run: the original scripts can overwrite an existing CSV.

Installation

Set up the environment for CAMP1–4.

CAMP is distributed as standalone Python scripts. The following pages explain how to run the regular and on-the-fly scripts already included in the repository.

1. Download CAMP

Terminal
git clone https://github.com/danrongLi/CAMP.git
cd CAMP

2. Create a Python environment

Use Python 3.10 for the dependency list supplied with this guide.

Terminal
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip

On Windows, activate the environment with .venv\Scripts\activate instead. A conda environment with Python 3.10 is also suitable.

3. Install dependencies

Terminal
python -m pip install -r docs/requirements.txt

The dependency list is included with this documentation. If your checkout does not yet contain docs/, download the file and install it with python -m pip install -r requirements.txt. It includes SEACells, used by CAMP4, and its progress-bar dependency.

Run the commands on the following pages from the CAMP repository root, with this environment active.

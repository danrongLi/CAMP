Regular CAMP

Run the regular CAMP1–4 scripts supplied for the PBMC analysis.

Script location

Repository folder
MetaCell_Construction_Pipeline/CAMP/without_on_the_fly_for_pbmc_data/
    CAMP1.py
    CAMP2.py
    CAMP3.py
    CAMP4.py

1. Set the input and output paths

Download the relevant input from the dataset folder. Open the script you want to run and edit its if __name__ == '__main__': block:

  • Set input_file to your local input file.
  • Set output_file in CAMP1–3, or out_csv in CAMP4, to a distinct CSV path for each method.
  • Create the output directory before running the script.

CAMP1–3 read a PBMC .h5ad file and perform filtering, normalization, log transformation, selection of highly variable genes, scaling and PCA. CAMP4 reads an already processed .h5ad file and computes PCA only if it is missing. CAMP1–3 do not automatically save that processed input for CAMP4.

Check the input expression scale before running: do not repeat normalization and log transformation on an already transformed matrix, or treat signed scaled expression as raw counts. The supplied PBMC export may already be processed, so its preprocessing must be reviewed before using these main blocks.

2. Set the granularity

Edit gamma_list in the same main block. These scripts calculate the requested number of representatives from int(N / gamma), where N is the number of cells after preprocessing. Larger gamma values request fewer metacells; gamma is not the metacell count.

For example, 40,000 retained cells and gamma=40 request 1,000 representatives. Some groups can be empty after assignment, so check the resulting number of metacells in the CSV.

3. Run the scripts

After editing the paths and settings, run the desired variant:

Terminal
python MetaCell_Construction_Pipeline/CAMP/without_on_the_fly_for_pbmc_data/CAMP1.py
python MetaCell_Construction_Pipeline/CAMP/without_on_the_fly_for_pbmc_data/CAMP2.py
python MetaCell_Construction_Pipeline/CAMP/without_on_the_fly_for_pbmc_data/CAMP3.py
python MetaCell_Construction_Pipeline/CAMP/without_on_the_fly_for_pbmc_data/CAMP4.py

You can also open the corresponding script in your Python IDE and run it with the installed environment.

Memory requirements

Regular CAMP2 constructs a dense cell-by-cell similarity matrix. For 40,000 cells, one float64 matrix alone occupies about 12.8 GB; total memory use is higher. The regular preprocessing also contains dense conversions. Check your available memory before running a full dataset.

Output

Each script saves a CSV with cell identifiers as row names, one membership column per gamma, and corresponding _is_seed columns marking the initially sampled cells. For example, 40 contains memberships for gamma=40, and 40_is_seed contains seed flags. The number of unique membership labels gives the actual number of metacells.

Use a new output path for each run: the original scripts can overwrite an existing CSV.

Toy data walk through

Generate data, construct CAMP metacells, and calculate quality metrics.

This small example uses 200 artificial cells and 500 genes. It runs CAMP1–4 using the existing on-the-fly functions, then evaluates the resulting memberships. No dataset or partition download is needed.

The purpose is to learn the workflow and check your installation—not to compare methods scientifically or reproduce the manuscript results. These data do not represent real PBMCs.

Run the complete example

First complete Installation. Download the Python example and save it in the CAMP repository root. Then run:

Terminal
python synthetic_walkthrough.py

Everything is saved in tutorial_runs/synthetic/. The script refuses to overwrite an existing directory. For another run, use python synthetic_walkthrough.py --output tutorial_runs/synthetic_2.

The same code is explained below. If copying the blocks instead, place all four Python blocks in one file in the order shown; they share variables. The setup and data block below includes the imports.

1. Generate the synthetic cells

We generate four artificial cell types with 50 cells each. Each type has a different block of higher-expression genes; sampling adds cell-to-cell variation. These labels are used only to evaluate purity, not to construct metacells.

Python — setup and data
from pathlib import Path
import argparse
import json
import os
import runpy
from importlib.metadata import version

parser = argparse.ArgumentParser(description=__doc__)
parser.add_argument("--repo", type=Path, default=Path.cwd())
parser.add_argument("--output", type=Path, default=Path("tutorial_runs/synthetic"))
args = parser.parse_args()

repo = args.repo.expanduser().resolve()
out = args.output.expanduser().resolve()
source = repo / "MetaCell_Construction_Pipeline/CAMP/on_the_fly_for_human_fetal_atlas_data"
for number in range(1, 5):
    if not (source / f"CAMP{number}.py").is_file():
        raise FileNotFoundError("Run from the CAMP repository root or set --repo.")
out.mkdir(parents=True, exist_ok=False)  # Refuse to overwrite a previous run.
os.environ.setdefault("MPLCONFIGDIR", str(out / "_cache/matplotlib"))
os.environ.setdefault("NUMBA_CACHE_DIR", str(out / "_cache/numba"))

import anndata as ad
import numpy as np
import pandas as pd
import scanpy as sc
from scipy import sparse
from sklearn.metrics import pairwise_distances
from sklearn.preprocessing import normalize

seed = 42
gamma = 10

rng = np.random.default_rng(seed)
types = np.repeat(["Type A", "Type B", "Type C", "Type D"], 50)
background = rng.gamma(shape=1.5, scale=1.2, size=500)
means = np.tile(background, (len(types), 1))
for index, label in enumerate(["Type A", "Type B", "Type C", "Type D"]):
    means[types == label, index * 20:(index + 1) * 20] *= 6
means *= rng.lognormal(mean=0, sigma=0.2, size=(len(types), 1))
counts = rng.negative_binomial(n=3, p=3 / (3 + means)).astype(np.float32)

adata = ad.AnnData(
    X=sparse.csr_matrix(counts),
    obs=pd.DataFrame(
        {"cell_type": pd.Categorical(types)},
        index=[f"toy_cell_{i:03d}" for i in range(len(types))],
    ),
    var=pd.DataFrame(index=[f"ToyGene{i:03d}" for i in range(counts.shape[1])]),
)
adata.layers["counts"] = adata.X.copy()
adata.uns["data_notice"] = "Synthetic teaching data, not biological observations."
print("Generated:", adata.n_obs, "cells and", adata.n_vars, "genes")

2. Prepare the data

Normalize the counts and log-transform expression, then compute 20 uncentered SVD components from 200 highly variable genes. This uses Scanpy's PCA call with zero_center=False, as in the supplied atlas preprocessing, and stores the coordinates in X_pca. The full 500-gene expression matrix is retained. A shared diffusion map provides the coordinates for compactness and separation.

Python — preparation
sc.pp.normalize_total(adata, target_sum=10000)
sc.pp.log1p(adata)
sc.pp.highly_variable_genes(adata, n_top_genes=200, flavor="seurat")
pca_data = adata[:, adata.var["highly_variable"]].copy()
sc.tl.pca(pca_data, n_comps=20, zero_center=False, random_state=seed)
adata.obsm["X_pca"] = pca_data.obsm["X_pca"].copy()

# A shared diffusion map is used only to evaluate the resulting partitions.
sc.pp.neighbors(adata, n_neighbors=15, use_rep="X_pca", random_state=seed)
sc.tl.diffmap(adata, n_comps=15, random_state=seed)
adata.write_h5ad(out / "synthetic_prepared.h5ad")

3. Construct CAMP metacells

With gamma=10, 200 cells request 20 representatives. This is an average target, not a requirement that every metacell contains ten cells.

runpy.run_path loads the functions from each existing CAMP script without running its dataset-specific main block. No CAMP algorithm is rewritten. For CAMP2 and CAMP3, X_simi selects the original on-the-fly similarity branch; it does not require a global similarity matrix.

Python — CAMP1–4
memberships = {}
for number in range(1, 5):
    method = f"CAMP{number}"
    functions = runpy.run_path(str(source / f"{method}.py"), run_name=f"toy_{method}")
    run_data = adata.copy()
    if number == 2:
        run_data.obsm["X_unit"] = normalize(
            run_data.obsm["X_pca"].astype(np.float32), axis=1
        )
    np.random.seed(seed)
    m_list, _ = functions["create_m_list"](run_data, [gamma])
    runner = "SEACells_mcRigor_fixed" if number == 4 else "SEACells_mcRigor"
    csv_path = out / f"{method.lower()}_membership.csv"
    functions[runner](
        run_data,
        [gamma],
        m_list,
        output_file=str(csv_path),
        reduction_key="X_simi" if number in (2, 3) else "X_pca",
        annotations=None,
    )
    frame = pd.read_csv(csv_path, index_col=0, dtype=str)
    if not frame.index.is_unique or set(frame.index) != set(adata.obs_names):
        raise ValueError(f"{method}: membership cell IDs do not match the input.")
    labels = frame[str(gamma)].reindex(adata.obs_names)
    if labels.isna().any():
        raise ValueError(f"{method}: missing memberships.")
    memberships[method] = labels
    print(method, "produced", labels.nunique(), "nonempty metacells")

Each variant receives the same prepared input and random seed. The returned memberships are aligned by cell identifier before evaluation; row order alone is not assumed.

4. Calculate quality metrics

The calculation below uses the definitions in Calculate_Quality_Metrics/camp1.py. That batch script contains dataset-specific file reads, so the short metric calculations are shown directly here.

MetricWhat it measuresInterpretation
PurityFraction of cells belonging to the most common artificial type within a metacell.Higher, up to 1.
CompactnessNegative mean variance across diffusion-map coordinates within a metacell.Higher (closer to zero) means less spread.
SeparationDistance from a metacell's diffusion-map centroid to the nearest other centroid.Higher means more separated centroids.
INV95th percentile, across genes, of within-metacell variance divided by mean expression.Lower indicates less normalized expression variation on this input scale.

Here INV uses the log-normalized expression matrix, and all methods share the same diffusion coordinates. The summary takes an unweighted mean across metacells: a small and a large metacell contribute equally.

Python — evaluation and summary
diffusion = np.asarray(adata.obsm["X_diffmap"])
expression = adata.X.toarray()  # Small teaching matrix only: 200 x 500.
per_metacell = []

for method, labels in memberships.items():
    groups = {
        metacell: np.flatnonzero(labels.to_numpy() == metacell)
        for metacell in labels.unique()
    }
    centroids = np.vstack([diffusion[indices].mean(axis=0) for indices in groups.values()])
    distances = pairwise_distances(centroids)
    np.fill_diagonal(distances, np.inf)
    separations = distances.min(axis=1) if len(groups) > 1 else np.array([np.nan])

    for (metacell, indices), separation in zip(groups.items(), separations):
        cell_types = adata.obs["cell_type"].iloc[indices]
        purity = cell_types.value_counts().max() / len(indices)
        compactness = -np.var(diffusion[indices], axis=0).mean()
        block = expression[indices]
        inv = np.percentile(block.var(axis=0) / (block.mean(axis=0) + 1e-8), 95)
        per_metacell.append({
            "method": method,
            "metacell": metacell,
            "n_cells": len(indices),
            "purity": purity,
            "compactness": compactness,
            "separation": separation,
            "INV": inv,
        })

metrics = pd.DataFrame(per_metacell)
metrics.to_csv(out / "metrics_per_metacell.csv", index=False)
grouped = metrics.groupby("method", sort=True)
summary = grouped.agg(
    metacells=("metacell", "size"),
    min_cells=("n_cells", "min"),
    median_cells=("n_cells", "median"),
    max_cells=("n_cells", "max"),
    mean_purity=("purity", "mean"),
    mean_compactness=("compactness", "mean"),
    mean_separation=("separation", "mean"),
    mean_INV=("INV", "mean"),
)
summary.to_csv(out / "metrics_summary.csv")
print("\nMetric means give each nonempty metacell equal weight:")
print(summary.to_string(float_format=lambda value: f"{value:.5g}"))

metadata = {
    "synthetic": True,
    "seed": seed,
    "gamma": gamma,
    "cells": adata.n_obs,
    "genes": adata.n_vars,
    "hvg_count": int(adata.var["highly_variable"].sum()),
    "pca_components": 20,
    "pca_zero_center": False,
    "diffmap_components": 15,
    "implementation": str(source.relative_to(repo)),
    "versions": {name: version(name) for name in
                 ["numpy", "scanpy", "scikit-learn", "SEACells", "ipywidgets"]},
}
(out / "run_settings.json").write_text(json.dumps(metadata, indent=2) + "\n")
print("\nResults saved in", out)

5. Read the results

Open metrics_summary.csv to see one row per method. Inspect the actual metacell counts and sizes alongside the four metric means. metrics_per_metacell.csv contains the individual values, and the four camp*_membership.csv files identify which cells belong together.

Smaller metacells can appear purer and more compact simply because they contain fewer cells; a singleton has purity 1 and zero within-group variance. Metrics also depend on preprocessing, gamma and random sampling. Do not interpret a winner in this artificial example as evidence of superiority on biological data.

The saved synthetic_prepared.h5ad contains the expression data and embeddings; run_settings.json records the settings and package versions. Numerical results can vary across software versions. This walkthrough covers partition quality, not donor-level differential expression or robustness benchmarking.
